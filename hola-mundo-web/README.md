# Hola Mundo (web)

Una página. Un fichero. Texto centrado sobre naranja, con seis círculos blancos
orbitando alrededor a tres velocidades distintas.

**URL pública:** https://jmsalash-ideas.github.io/hola-mundo-web/

## Por qué existe

No es la página. La página es la excusa.

Esto es el piloto de un flujo: una idea se especifica, se aprueba, se construye
y se publica **sin que el usuario toque el servidor local en ningún momento**.
Revisar la spec desde el móvil, aprobar desde el móvil, ver el resultado desde
el móvil. Si la página queda perfecta pero hay que abrir el portátil, el piloto
ha fallado.

De ahí que el repositorio sea público (Pages sobre repo privado exige plan de
pago, y aquí no hay nada que proteger) y que todo el desarrollo ocurra en la
instancia cloud.

## Qué hay dentro

| Fichero | Contenido |
|---|---|
| `index.html` | La página completa, autocontenida. |
| `README.md` | Esto. |
| `docs/` | La spec y el plan que la produjeron. |

`index.html` funciona también abierto directamente desde el disco: no hay JS, ni
build, ni dependencias, ni una sola petición de red más allá del propio HTML.

Con «reducir movimiento» activado en el sistema, las formas se quedan quietas en
una composición estática y el fondo deja de moverse.
